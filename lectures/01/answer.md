## 宿題

- 取り組んだレベル：実装
- やったこと：
  - `app/ask.py` に `--chat` オプションを追加した（`uv run python -m app.ask --chat`）。
  - `client.chats.create(model=MODEL)` で会話セッションを作り、入力ループで `chat.send_message()` を呼ぶ。chats オブジェクトがそれまでのやり取りを履歴として保持し、毎回まとめてモデルに送る。
  - 空行・`exit`・Ctrl-D で終了。API エラー（429 など）はメッセージを表示して会話を継続する。
  - 各ターンで入力／出力トークン数を表示する（演習で作った表示処理を `print_usage()` に切り出して共用）。
  - 引数なし／質問を渡す既存の1回呼び出しの動作は変えていない。
- 結果：
  - 1ターン目「私の名前は太郎です。一言で返事してください。」→「こんにちは、太郎さん！」（入力 14 / 出力 5）
  - 2ターン目「私の名前は何でしたか？一言で答えてください。」→「太郎。」（入力 34 / 出力 2）
  - 2ターン目で1ターン目の内容を踏まえて答えられた。
- 気づき・疑問：
  - 2ターン目の入力トークン数（34）は、2ターン目の質問だけでなく1ターン目の質問と応答を含んだ数になっている。会話履歴は「モデルが覚えている」のではなく、毎回クライアント側から履歴を丸ごと送り直しているため、会話が長くなるほど入力トークン（＝コストとレート制限の消費）が増えていく。
